💻 Principais Sistemas Operacionais

Windows, Linux, macOS, Android e iOS: cada dispositivo tem seu S.O. Vamos conhecer as diferenças, vantagens e quando usar cada um.

📊 Segundo dados de 2024: Windows lidera desktops (~72%), Android domina celulares (~72%) e Linux é o rei dos servidores web (mais de 90% da internet).

🪟 Windows

O Windows é o sistema operacional mais usado em computadores pessoais no mundo. Criado pela Microsoft, ele se tornou padrão em empresas, escolas e residências pela sua compatibilidade enorme com hardware e software.

Pense no Windows como o shopping center do mundo digital: tem de tudo, para todo mundo, com muitas lojas (programas) e uma entrada fácil (interface intuitiva).

Pontos positivos e negativos

✔ Pontos positivos
  • Fácil de usar — interface intuitiva
  • Suporte ao maior número de softwares
  • Melhor ecossistema de jogos
  • Compatível com praticamente todo hardware
✖ Pontos negativos
  • Licença paga
  • Mais suscetível a vírus e malware
  • Consome mais recursos do sistema
  • Atualizações podem ser forçadas

🐧 Linux

O Linux é um sistema operacional gratuito e de código aberto (open source): qualquer pessoa pode ver, modificar e distribuir seu código. Por isso existem dezenas de versões chamadas distribuições (distros).

Pense no Linux como um kit de montar: você pega a base (o kernel) e monta do seu jeito. Por isso existe desde o Ubuntu (fácil para iniciantes) até o Arch (feito por quem quer controle total).

✔ Pontos positivos
  • Gratuito e open source
  • Muito seguro e estável
  • Leve: roda em hardware antigo
  • Alta personalização
✖ Pontos negativos
  • Curva de aprendizado maior
  • Menos suporte a softwares comerciais
  • Jogos com limitações (embora melhore)
  • Drivers podem apresentar problemas

🍎 macOS

O macOS é o sistema operacional dos computadores Apple (MacBook, iMac, Mac Mini). Diferente dos demais, ele só funciona em hardware Apple — essa união entre hardware e software resulta em um sistema muito estável e otimizado.

Pense no macOS como um carro de luxo: tudo é integrado, refinado e funciona perfeitamente junto — mas você não pode trocar as peças por qualquer outra.

✔ Pontos positivos
  • Alta estabilidade e pouco travamento
  • Design refinado e consistente
  • Segurança robusta
  • Integração perfeita com iPhone e iPad
✖ Pontos negativos
  • Hardware Apple é caro
  • Menos softwares que Windows
  • Pouco customizável
  • Jogos com suporte limitado

📱 S.O. Móveis: Android e iOS

Nos celulares e tablets, dois sistemas dominam: Android (Google) e iOS (Apple). Ambos são feitos para telas táteis, bateria e conectividade, mas têm filosofias bem diferentes.

Característica 📱 Android (Google) 🍏 iOS (Apple)
Código Open source (AOSP) Fechado (proprietário)
Dispositivos Samsung, Motorola, Xiaomi… Apenas iPhone e iPad
Personalização Alta Média
Segurança Boa Muito alta
Atualizações Varia por fabricante 5+ anos garantidos
Preço Diversas faixas Premium (mais caro)

🔍 Windows vs Linux vs macOS

Cada sistema tem seu ponto forte. Não existe o "melhor" — existe o mais adequado para cada situação e perfil de usuário.

* O macOS é gratuito, mas o hardware Apple é caro.

💡 Qual escolher? O Windows é ideal para uso geral e jogos. O Linux é a escolha para servidores, programadores e quem quer privacidade. O macOS brilha para profissionais criativos dentro do ecossistema Apple.

📝 Verifique seu Conhecimento

Leia cada situação e escolha o Sistema Operacional mais adequado.

1. Um estudante quer jogar os últimos lançamentos de games e precisa de máxima compatibilidade. Qual S.O. é mais indicado?

AWindows — maior base de games e suporte de fabricantes de GPUs
BLinux — gratuito e leve para rodar jogos
CmacOS — melhor desempenho gráfico
DAndroid — sistema mais rápido
✔ Correto! O Windows domina o mercado de games com suporte nativo de fabricantes de hardware e estúdios de jogos.
✖ Não é o melhor para games. Embora o Linux tenha melhorado com o Proton/Steam, e o macOS tenha boa GPU, nenhum se compara ao ecossistema do Windows para jogos.

2. Uma empresa precisa de um servidor web estável, seguro e gratuito. Qual S.O. é o mais utilizado nesse cenário?

AWindows Server — mais fácil de configurar
BLinux — gratuito, estável e dominante em servidores
CmacOS Server — muito seguro
DAndroid — baseado em Linux
✔ Correto! Mais de 70% dos servidores web do mundo rodam Linux — é gratuito, estável, seguro e altamente configurável.
✖ O Windows Server existe, mas tem custo de licença. O Linux é a escolha dominante no mercado de servidores.
✖ O macOS Server foi descontinuado pela Apple e exige hardware exclusivo Apple.
✖ O Android é baseado no kernel Linux, mas é projetado para móveis, não para servidores web.

3. Maria comprou um smartphone Samsung. Qual sistema operacional ela provavelmente usa?

AiOS — sistema da Apple
BWindows Mobile — sistema da Microsoft
CAndroid — sistema do Google, usado pela Samsung
DLinux puro — sistema open source
✔ Correto! A Samsung usa Android (com a interface One UI por cima). O iOS é exclusivo do iPhone.
✖ O iOS é exclusivo da Apple. Apenas iPhones e iPads o utilizam.
✖ O Windows Mobile foi descontinuado pela Microsoft em 2019.
✖ O Android é baseado no kernel Linux, mas é um sistema próprio. Linux puro não é comum em smartphones.

4. João é designer e comprou um MacBook Pro. Qual S.O. encontrará pré-instalado?

AWindows 11
BUbuntu Linux
CChrome OS
DmacOS — sistema exclusivo da Apple
✔ Correto! Todos os computadores Mac vêm com macOS pré-instalado. É exclusivo do hardware Apple.
✖ O MacBook usa exclusivamente o macOS, próprio da Apple. Ele vem com macOS de fábrica.

5. Qual das alternativas descreve corretamente o Linux?

AÉ um sistema pago desenvolvido pela Microsoft
BÉ gratuito, open source e disponível em distribuições como Ubuntu e Fedora
CÉ exclusivo de computadores Mac
DSó pode ser usado em servidores
✔ Correto! O Linux é open source, gratuito e existe em dezenas de distribuições: Ubuntu, Fedora, Debian, Arch, Mint, entre outras.
✖ O Linux não tem relação com a Microsoft. Foi criado por Linus Torvalds em 1991 e é mantido pela comunidade.
✖ Exclusivo da Apple é o macOS. O Linux roda em qualquer hardware compatível.
✖ O Linux pode ser usado normalmente como desktop. Ubuntu e Linux Mint são exemplos populares para uso pessoal.

6. Ana tem um iPhone e quer compartilhar fotos com seu MacBook automaticamente. Qual recurso da Apple permite isso?

AGoogle Drive — armazenamento em nuvem
BOneDrive — nuvem da Microsoft
CiCloud — ecossistema integrado da Apple
DBluetooth manual entre os dispositivos
✔ Correto! O iCloud é o serviço de nuvem da Apple que integra automaticamente iPhone, iPad, MacBook e Apple Watch.
✖ O Google Drive funciona, mas não é a integração nativa e automática do ecossistema Apple. O iCloud faz isso nativamente.
✖ OneDrive é da Microsoft e integra com Windows/Office. No ecossistema Apple, o serviço integrado é o iCloud.
✖ Bluetooth funcionaria manualmente, mas o ecossistema Apple usa o iCloud para sincronização automática entre dispositivos.

🛠️ Atividade Prática — Conhecendo Outros S.O.

⏱ ~25 min 🌐 Requer internet 📍 Sem instalação

📋 Materiais necessários

  • Computador com Windows 10 ou 11
  • Navegador com acesso à internet
  • Caderno ou documento de texto para anotar
1
Descobrir a versão do Windows

Pressione Win+R, digite winver e pressione Enter. Anote a versão exata e compare com os colegas.

2
Linux no navegador

Abra o navegador e acesse distrosea.com. Selecione Ubuntu 22.04 LTS e clique em Start. Você usará Linux de verdade no navegador.

3
Explore o Ubuntu

Dentro do Ubuntu virtual, localize: o gerenciador de arquivos, o terminal e as configurações. Clique no menu de aplicativos (grade de pontos).

4
Compare com o Windows

Volte ao Windows e abra Configurações (Win+I). Compare os menus dos dois sistemas. Qual é mais fácil para você? Por quê?

5
Tabela de semelhanças e diferenças

Escreva 3 semelhanças e 3 diferenças que você observou entre o Windows e o Ubuntu.

6
Registrar conclusões

Responda: qual S.O. você prefere para uso diário? E para um servidor? Justifique sua resposta com base no que explorou.

📌 Para saber: Embora a aparência seja diferente, Windows e Ubuntu realizam as mesmas funções básicas: gerenciar arquivos, executar programas e configurar hardware. A maior diferença está no modelo: Windows é proprietário e pago; Ubuntu é open source e gratuito.
