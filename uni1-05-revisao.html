1. Qual tecla apaga o caractere imediatamente à esquerda do cursor?

ADelete
BBackspace
CEsc
DTab
✔ Correto! O Backspace apaga o caractere à esquerda do cursor. Já o Delete apaga o caractere à direita.
✖ O Delete apaga o caractere à direita do cursor, não à esquerda.
✖ O Esc cancela ou fecha a operação atual, não apaga caracteres.
✖ O Tab insere uma tabulação ou move o foco para o próximo campo.

2. O atalho Ctrl + Z realiza qual operação?

ACopiar o texto selecionado
BFechar a janela ativa
CDesfazer a última ação
DSelecionar todo o conteúdo
✔ Correto! Ctrl+Z desfaz a última ação realizada. É um dos atalhos mais úteis do dia a dia.
✖ Copiar é Ctrl+C. O Ctrl+Z desfaz a última ação.
✖ Fechar janela é Alt+F4. O Ctrl+Z desfaz a última ação.
✖ Selecionar tudo é Ctrl+A. O Ctrl+Z desfaz a última ação.

3. O kernel de um sistema operacional é responsável por:

AGerenciar diretamente o hardware (CPU, memória, dispositivos)
BExibir ícones e janelas na área de trabalho
CInstalar programas no computador
DOrganizar arquivos em pastas
✔ Correto! O kernel é o núcleo do S.O. — ele se comunica diretamente com o hardware e é a camada mais profunda do sistema.
✖ A exibição da interface gráfica (janelas, ícones) é função da GUI, não do kernel.
✖ Instalar programas é tarefa do gerenciador de pacotes ou instalador, não do kernel.
✖ A organização de arquivos é feita pelo sistema de gerenciamento de arquivos, que é uma camada acima do kernel.

4. Qual é a diferença entre uma interface CLI e uma interface GUI?

ACLI só funciona no Linux; GUI só funciona no Windows
BCLI é mais moderna e fácil de usar
CAmbas são idênticas, apenas com visuais diferentes
DCLI usa comandos de texto; GUI usa ícones, janelas e mouse
✔ Correto! CLI (Command Line Interface) é baseada em texto (ex.: Prompt de Comando). GUI (Graphical User Interface) usa elementos visuais como ícones e janelas.
✖ CLI e GUI existem em todos os S.O. principais. O Windows tem o Prompt de Comando (CLI) e a Área de Trabalho (GUI), por exemplo.
✖ CLI é mais antiga e requer conhecimento técnico, mas ainda é amplamente usada por administradores de sistemas.
✖ São formas fundamentalmente diferentes de interação: uma baseada em texto, outra em elementos gráficos.

5. Qual sistema operacional domina mais de 90% dos servidores que sustentam a internet?

AWindows Server
BmacOS Server
CLinux
DAndroid
✔ Correto! O Linux domina a infraestrutura de servidores da internet gratuito, estável e altamente configurável. Grandes empresas como Google, Amazon e Meta rodam Linux.
✖ O Windows lidera nos PCs pessoais (~72%), mas nos servidores de internet o Linux é dominant.
✖ O macOS é popular entre profissionais criativos, mas sua presença em servidores é pequena.
✖ O Android domina os smartphones (~72%), não os servidores de internet.

6. Uma das principais características do Linux é:

AÉ proprietário e desenvolvido pela Microsoft
BÉ gratuito, open-source e possui várias distribuições (distros)
CSó funciona em computadores da Apple
DNão possui interface gráfica
✔ Correto! O Linux é open-source (código aberto) e gratuito. Existem diversas distribuições como Ubuntu, Debian, Fedora e Mint, cada uma com características diferentes.
✖ Quem é desenvolvido pela Microsoft é o Windows. O Linux foi criado por Linus Torvalds e é mantido pela comunidade.
✖ O sistema exclusivo da Apple é o macOS. O Linux roda em praticamente qualquer hardware.
✖ O Linux possui diversas interfaces gráficas (GNOME, KDE, etc.). A CLI é uma opção, não uma obrigatoriedade.

7. O caminho C:\Usuários\Ana\Documentos\relatorio.pdf indica:

AO nome do programa que abre o arquivo
BA data de criação do arquivo
CO tipo de backup utilizado
DA localização completa do arquivo na árvore de diretórios
✔ Correto! Esse é o caminho (path) do arquivo: começa na raiz C:\, passa pelas pastas Usuários → Ana → Documentos e termina no arquivo relatorio.pdf.
✖ Esse é o caminho do arquivo — indica exatamente onde ele está na hierarquia de pastas do disco.

8. Você deseja enviar 30 fotos por e-mail, mas o tamanho total é muito grande. Além disso, quer que o destinatário receba um único arquivo. Qual operação é mais adequada?

ACompactar as fotos em um arquivo .zip
BRenomear todos os arquivos antes de enviar
CMover as fotos para a Lixeira e enviar de lá
DAlterar a extensão de .jpg para .pdf
✔ Correto! Compactar em .zip reduz o tamanho e agrupa todos os arquivos em um único pacote — ideal para envio por e-mail.
✖ Renomear os arquivos não reduz o tamanho nem os agrupa em um único arquivo.
✖ A Lixeira não é um local de envio. Arquivos lá aguardam exclusão definitiva.
✖ Mudar a extensão manualmente não converte o arquivo — o conteúdo continua sendo uma imagem e o arquivo pode se tornar inutilizável.

9. Qual extenção é utilizada por planilhas do Microsoft Excel?

A.docx
B.xlsx
C.pptx
D.pdf
✔ Correto! .xlsx é o formato padrão do Excel. O .docx é do Word, o .pptx é do PowerPoint, e o .pdf é um formato de leitura universal.
✖ .docx é o formato do Microsoft Word (documentos de texto).
✖ .pptx é o formato do Microsoft PowerPoint (apresentações).
✖ .pdf é um formato de documento portátil para distribuição e leitura, não uma planilha.

10. O layout de teclado padrão no Brasil, com a tecla extra entre o Shift esquerdo e o Z (geralmente com o ç), chama-se:

AQWERTY US
BAZERTY
CQWERTZ
DABNT2
✔ Correto! O ABNT2 é o layout padrão brasileiro. Possui uma tecla extra com ç e acentos próprios do português, além da tecla ¸ ao lado do L.
✖ O QWERTY US é o layout americano — sem a tecla extra e sem o ç dedicado.
✖ O AZERTY é o layout usado na França e Bélgica, com as letras A/Q e Z/W trocadas.
✖ O QWERTZ é o padrão da Alemanha e Europa Central, com Y e Z trocados.

📋 Pontos-chave da Unidade 1

  • O teclado ABNT2 é o padrão brasileiro, com tecla extra e o ç dedicado
  • Teclas modificadoras (Shift, Ctrl, Alt, Win) por si só não fazem nada — combinam com outras teclas para criar atalhos
  • O sistema operacional é o intermediário entre o hardware e os programas; o kernel é seu núcleo
  • Principais funções do S.O.: gerenciar processos, memória, arquivos e dispositivos
  • Windows domina PCs; Linux domina servidores; Android domina smartphones
  • O caminho de um arquivo mostra onde ele está na árvore de diretórios (ex.: C:\Docs\arquivo.pdf)
  • A extensão (.pdf, .xlsx, .mp4…) define o tipo do arquivo e qual programa o abre
  • Operações essenciais com arquivos: criar, renomear, copiar, mover, excluir e pesquisar
