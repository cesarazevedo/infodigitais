Aula 2.1 — Como funciona o acesso à internet, os principais navegadores e o uso profissional do e-mail

💬 O que é um navegador web?

Um navegador web (browser) é o programa que permite acessar e visualizar páginas da internet. Ele funciona como um interpretador: recebe arquivos em HTML, CSS e JavaScript dos servidores e os transforma na página que você vê na tela.

O navegador é a porta de entrada para a internet. Conhecer bem seus recursos é essencial para navegar com eficiência, segurança e privacidade.

🧩 Principais Navegadores

Existem vários navegadores disponíveis, cada um com características próprias. Chrome, Edge e Brave usam o mesmo motor (Blink); Firefox usa Gecko e Safari usa WebKit.

📌 Chrome, Edge e Brave usam o mesmo motor (Blink), por isso páginas se comportam de forma semelhante neles. Firefox e Safari têm motores próprios — o que pode causar pequenas diferenças visuais em alguns sites.

📧 E-mail — Conceitos Básicos

O e-mail é um dos serviços mais antigos e ainda mais utilizados da internet. Permite enviar e receber mensagens e arquivos entre pessoas ao redor do mundo.

Você pode acessar o e-mail via Webmail (pelo navegador, sem instalar nada: Gmail, Outlook.com) ou por um cliente de e-mail instalado no computador (Outlook, Thunderbird), que permite uso offline.

Ctrl+Shift+N é o atalho para o modo anônimo. Ctrl+T abre nova aba normal, Ctrl+H abre histórico e Ctrl+D salva favorito.

3. O que garante que um site usa HTTPS?

O cadeado na barra de endereços, indicando criptografia TLS
O site ter um design bonito e profissional
O site ser acessado pelo Chrome

Correto! O cadeado indica que a conexão usa TLS/SSL, criptografando os dados trocados entre você e o servidor.
O design bonito não garante segurança. Apenas o cadeado (HTTPS/TLS) confirma que a conexão é criptografada.

4. Qual protocolo é responsável pelo envio de e-mails?

IMAP
POP3
HTTP
SMTP
Correto! SMTP (Simple Mail Transfer Protocol) é usado exclusivamente para enviar e-mails. IMAP e POP3 são para receber.
SMTP é o protocolo de envio. IMAP e POP3 são para recebimento. HTTP é para navegação na web.

5. Qual a principal diferença entre IMAP e POP3?

IMAP envia e-mails; POP3 recebe
IMAP mantém e-mails no servidor sincronizados; POP3 baixa e remove do servidor
IMAP é mais antigo que POP3
Não há diferença prática
Correto! Com IMAP os e-mails ficam sincronizados no servidor (acessível de qualquer dispositivo). POP3 baixa e geralmente remove do servidor.
Ambos servem para receber. A diferença é que IMAP sincroniza com o servidor e POP3 baixa os e-mails para o dispositivo.

Esse é um sinal clássico de phishing — uma tentativa de roubo de dados. Nunca fornecer senha ou dados bancários por e-mail.

Materiais necessários:

1
Verifique o HTTPS nos sites Acesse 3 sites diferentes. Em cada um, observe se há o cadeado na barra de endereços. Anote quais usam HTTPS e quais usam HTTP (sem cadeado).
2
Modo anônimo Pressione Ctrl+Shift+N para abrir aba anônima. Acesse o mesmo site da aba normal. Compare: o navegador já tem seus dados salvos na aba normal?

Salve um favorito Acesse o site do IFRN (ifrn.edu.br). Pressione Ctrl+D para favoritar. Nomeie descritivamente. Feche a aba e abra o site apenas pelos favoritos.
5
Configure sua assinatura de e-mail Acesse o Gmail ou webmail institucional. Vá em Configurações → Assinatura. Inclua: nome completo, turma/curso, instituição e e-mail de contato.

Redija um e-mail profissional Escreva um e-mail formal com dúvida sobre o conteúdo da unidade. Use assunto descritivo, saudação, corpo e despedida com sua assinatura. Envie para cesar.augusto@escolar.ifrn.edu.br.
